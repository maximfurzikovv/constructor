# Бесплатный деплой для проверки проекта

Этот вариант не требует карты: база данных в Neon Free, приложение на Render Free.

## 1. База данных Neon

1. Откройте https://neon.com и создайте бесплатный аккаунт.
2. Создайте новый проект PostgreSQL.
3. Скопируйте строку подключения `DATABASE_URL`.

## 2. Публикация кода

1. Загрузите проект в GitHub-репозиторий.
2. Откройте https://render.com и создайте бесплатный аккаунт.
3. Создайте новый Web Service из GitHub-репозитория.
4. Если Render увидит `render.yaml`, настройки подставятся автоматически.
5. В Environment добавьте переменную `DATABASE_URL` со строкой из Neon.
6. Убедитесь, что `NODE_ENV` равен `production`.
7. Запустите Deploy.

Если настройки вводятся вручную:

```text
Build Command: npm install --include=dev && npm run build
Start Command: npm run deploy:start
Health Check Path: /api/health
```

## 3. Проверка

После деплоя Render выдаст ссылку вида:

```text
https://excursion-constructor.onrender.com
```

Откройте ее с телефона. Админка, конструктор, опубликованный сайт и прохождение экскурсии будут работать по этой ссылке.

## Ограничения бесплатного варианта

- Render Free засыпает после простоя, первый запуск может занять около минуты.
- Локальные файлы на Render временные, поэтому новые медиа-загрузки сохраняются в базе как `data:` URL.
- Загружаемые файлы ограничены 8 МБ, чтобы не переполнить бесплатную БД.
- Бесплатная ссылка будет поддоменом Render. Собственный купленный домен без оплаты регистратора получить нельзя.

## Быстрый временный показ без деплоя

Для разовой проверки можно использовать Cloudflare Quick Tunnel:

```bash
cloudflared tunnel --url http://localhost:3001
```

Это даст временную публичную ссылку `trycloudflare.com`, но компьютер должен оставаться включенным.
